# 确认费用预算 v1

生命周期见 [契约索引](README.md)。这是用户确认的单笔全部交易费用上界，不是券商费率计算器，
也不是订单、扣款或收益承诺。不存在默认费率或默认零费用。

## 预算文档

文档为 `{"schema_version": 1, "budgets": [...]}`。每条预算必须提供：

| 字段 | 含义 |
|---|---|
| `id` | 预算标识 |
| `account_id` | 已录入账户的稳定别名 |
| `instrument_id` | 精确标的，例如 `a:518880` 或 `us:SPY`，不接受通配符 |
| `market` / `currency` | 当前仅支持 `a` / `CNY` 或 `us` / `USD` |
| `valid_from` / `valid_until` | 带时区的有效区间，包含起点、不包含终点 |
| `max_quantity` | 此费用上界覆盖的最大股数 |
| `max_notional` | 此费用上界覆盖的最大购入本金，币种同上 |
| `fee_upper_bound` | 单笔全部费用的正数上界，币种同上 |
| `source` | 用于确认上界的券商说明或用户预算依据 |

金额建议用十进制字符串，最多 8 位小数、单字段不超过 1e18。预算不是百分比费率。
同账户、标的、币种只允许一条预算，重复 ID/范围和未知字段均拒绝。
适用订单必须同时满足数量和本金上限；费用上界必须涵盖该范围内全部佣金、平台及其他交易费用。
零费用、外币收费、换汇、融资、分拆为多笔订单等未支持语义不得隐式折算。

可先整理未知项，但只有字段完整且来源明确才能确认。具体费率/上界由用户确认，代码不代填。

## 接口与撤销

CLI：`--fee-budget-preview JSON` 只读验证；`--fee-budget-state` 读取文档与确认来源；
`--fee-budget-replace JSON --confirmed` 替换完整预算集合。

MCP：`fee_budget_preview(document)`、`fee_budget_state()`、
`fee_budget_replace(document, confirmed=true)`。必须先展示拟替换内容、再获得用户明确确认。
Engine 写接口也要求显式确认和 CLI/MCP 渠道；只有调用方声称来源并不替代真实用户授权。

完整替换会删除当前集合中未列出的预算。确认替换为 `{"schema_version":1,"budgets":[]}`
撤销全部当前预算。不提供从 LLM 输出自动写入预算的路径。
文档写入 `.local/fee_budgets.json`，确认事件沿用内容哈希侧账；文件修改、事件缺失或损坏均不能用作确认事实。
写入或确认途中失败不会自动批准，读取会报告未知或未验证。

## 校验与展示

AnalysisContext 的可选 `fee_budgets` 字段保存读取状态；统一快照冻结完整文档和确认事件，
预算内容也影响快照哈希。旧上下文无此字段时保持预算缺失。
加仓检查确认时间不晚于快照、有效期、精确范围和数量/本金上限，然后以 Decimal 计算：

`所需现金 = 股数 × 快照价格 + 确认费用上界`

与同账户、同币种、已核对账单的可用现金比较，不借用预计卖出收入或其他账户资金。
费用校验结果冻结预算 ID、确认事件 ID、内容哈希、金额与有效期。
报告展示费用预留和含费现金需求，最终交付时再次检查预算有效期。
价格仍是快照估值，不是成交价格保证；实际费用必须以后续真实成交独立记录，不将预算写成实际费用。

当前只允许满足全部其他门禁的已有持仓 `add` 使用此机制。
`buy` 仍要求独立的新标的账户路由；同账户同币种多笔买入全部待复核，不按列表顺序挑一笔批准。
组合分桶/上限仍要求完整投影，费用通过不能解除该阻断。

预算不会锁定或消耗现金，不提供跨运行的订单/资金预留。同一账单上的多次分析不能理解为可累加执行的订单。
替换/撤销作用于后续分析；历史冻结产物保留原证据，不会被回写。用户修改预算或发生交易后必须重新分析，
不能把旧报告当作当前授权。生产排队产物的实时失效处理属于尚未验收的运行交付门禁。

## 验证边界

测试覆盖 A 股/美股币种范围、确认缺失/篡改、到期、金额边界、现金不足、撤销、同账户重复占用现金、
新标的继续阻断、展示一致性和只读边界。隔离命令：

```bash
.venv/bin/python scripts/smoke_fee_budget.py --output-dir /tmp/stocks-fee-budget-new
```

目标为仓库外新目录。烟测使用模拟事实和模型走真实调度、校验及报告代码；不联网、不发送、不下单。
它不能证明真实券商上界、真实账户、在线模型或 NAS 生产已验收。
