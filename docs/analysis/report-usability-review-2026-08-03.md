## 2. 拉低实际可用性的问题（按决策影响排序）

### P0-1 LLM 研判调用不稳定（核心价值半数缺席）

2026-08-03 盘后运行：`synthesis error: timed out` → outlook
unavailable。配置为单次调用、180s 超时、**无重试、无备用模型**
（`engine.yaml llm.outlook`，model `gpt-5.5`）。走势研判是用户核心
目标的第一价值，当前每个窗口都有掷硬币式缺席风险。

**建议**：超时重试（1 次）+ 备用模型链（如 gpt-5.5 → deepseek-v4-pro）
+ 失败时下一窗口优先补算。属于小改动，收益最大。

### P0-2 风险状态路径未锚定（原"滞留 19 天"结论已于深夜复核修正）

**修正**：原结论"风险状态滞留 19 天"**不成立**。运行产物链证明 TTL
自动解除机制存在且工作正常：7-31 hedge（新证据 escalated）→
8-03 06:08 过期重置为 normal → 8-03 15:12 新 critical 簇重新
escalated → 8-03 21:47 再次过期降级为 watch/candidate。盘后 payload
的"地缘政治 crisis"来自**当天新鲜**情报簇，不是 7-15 旧信号。

**但复核发现一个真实缺陷**：`_persist_risk_state` 用进程 CWD 解析
相对 `state_path`/`artifact_dir`，与 `resolve_artifact_dir`（锚定
repo_root）不一致。cron/agent 以不同工作目录启动时，风险状态会
**静默分裂成多份文件**各自演化。已于当晚修复为锚定仓库根目录
（含回归测试）。

同日报告风险状态不一致（开盘后"常态"/盘后"对冲"）的原因：开盘后
运行时情报尚未刷新（risk_eligible=false → 不评估簇 → normal），盘后
运行时新 critical 簇到达 → hedge。属设计内的诚实门控，但巡逻与会话
的调度时序值得优化（见 P1-3）。

### P1-1 情报层对持仓决策零方向输入

2026-08-03 cn_post_open：`intelligence_coverage.directional = 0`，
49 条全部为 category padding；每张持仓卡"未匹配到可用方向情报信号"。
当天巡逻实际采集 190 篇文章，但只产出 3 个事件簇（全部标记
CRYPTO，含一个 geopolitics critical）和 **0 条方向信号**
（`signals/2026-08-03/signal.json` 为空数组）。用户核心目标是
"结合新闻实事、产业报告、市场情绪"——这一条目前在持仓决策层
**没有兑现**，新闻只影响风险状态（且见 P1-2）。

### P1-2 风险触发源与组合无关

geopolitics critical 簇的 `affected_symbols = ['CRYPTO']`，用户不持有
任何加密资产，但该簇参与维持 hedge 状态、暂停全部加仓。情报→符号
映射过粗（疑似大量文章被归入 CRYPTO），风险引擎缺少"与组合相关性"
过滤。

### P1-3 数据新鲜度

- 支付宝/建行等场外资产数据停在 2026-07-03（1 个月），报告已在
  data_limitations 中披露，但估值偏差会传导到权重、约束、裁决；
- 宏观数据停在 2026-06-01（2 个月）；
- 情报摘要滞后 3 天（巡逻与会话调度时序：cn_post_open 14:10 运行时
  最新信号仍是 7-31 的，14:13 巡逻才刷新——先分析后巡逻的顺序颠倒）。

### P2-1 硬止损被"维持现状"默认分支压制

512480 浮亏 -30% 触发硬止损，但与"权益桶占比 14.5% < 25% 下限"
冲突，默认分支为"维持现状，等待人工确认"。对止损纪律而言，
hold 是风险最高的默认选项。这正是 `TASK-M4-constraint-model-upgrade.md`
（不可逆性/分池/硬上限）要解决的范畴，且 2026-07-31 外部对比报告
已证明此类约束对用户决策是核心。**M4 的优先级应重新评估。**

## 3. 对用户问题的直接回答

**"可以一定程度上参考它做决策了吗？"——分层回答：**

| 报告内容 | 可否参考 | 说明 |
|---|---|---|
| 资金状态/持仓估值/数据边界披露 | ✅ 可以 | 确定性计算，可追溯，含诚实的新鲜度标注 |
| 持仓动作候选（方向+参考金额） | ✅ 可以（需人工确认） | 裁决链路可信；但注意 P2-1，止损类信号被默认压制时要主动翻看 suppressed_actions_reference |
| 提前布局候选 | ⚠️ 半参考 | 纯技术面筛选，无情报输入；风险状态为 hedge 时全部带"暂停加仓"锁（当前 hedge 由 8-03 新鲜 critical 簇触发，非滞留） |
| 走势研判（LLM） | ⚠️ 有则可参考 | 成功时质量合格（有验证/证伪线）；但成功率不稳定，且 source_refs 只覆盖技术指标，新闻类论断无引用 |
| 情报驱动判断 | ❌ 目前不存在 | directional=0，新闻未进入持仓决策 |
